# Hyperbolicity-Dimension-2-Conventions-Facts-2026
A collection of codes and files for the conventions and facts related to new vanishing results for invariant (logarithmic) $2$-jet differentials in dimension $2$

##  Associated Paper

This repository contains the computational materials and Maple codes supporting the results presented in the following paper:

> **arXiv:2603.14881**
> **Title:** Vanishing of Invariant 2-Jet Differentials and Improved Hyperbolicity Degree Bounds in Dimension Two

##  Repository Contents

This repository primarily includes:

-   **Convention-Maple-codes&files:** Contains the subdirectories `Convention-Compact` and `Convention-Logarithmic` verifying conventions used in the computations.
    -   `Convention-Compact`: Includes the Maple code `convention cpt.mw` used to verify **Convention 4.18** in the associated paper, along with the export file `convention cpt.pdf`.
    -   `Convention-Logarithmic`: Includes the Maple code `convention log.mw` used to verify **Convention 3.16** in the associated paper, along with the export file `convention log.pdf`.
-   **Fact-Compact:** Contains PDF files which are exports generated by the Maple code for the compact case with adjusted parameters $d, m, t$ and $HUU$. These files cover the **Fact** in **Remark 6.3** of the associated paper.
-   **Fact-Logarithmic:** Contains PDF files which are exports generated by the Maple code for the logarithmic case with adjusted parameters $d, m, t$ and $HSS$. These files cover the **Fact** in **Remark 6.4** of the associated paper.

These files are intended to reproduce and verify the calculations found in the associated mathematical paper.

##  Usage

1.  Download the specific `.mw` files directly (using the "Download raw file" button on GitHub) or clone the repository to your local machine.
2.  Open the `.mw` files within the Maple environment.
3.  Execute the worksheets to regenerate the exports or modify parameters for further experimentation.
